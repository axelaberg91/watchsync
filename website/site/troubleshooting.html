Troubleshooting

Start with the symptom you can see, then work through the checks in order.

I cannot open watchsync.local

  1. Join the same normal Wi-Fi network as Watchsync.
  2. Type http://watchsync.local explicitly, or use http://<your-hostname>.local if you renamed the device under Network settings. After a hostname change and restart, the old name stops being advertised. The device serves HTTP.
  3. Find the device’s IP in the router’s connected-device list and open that address.
  4. Check for guest-network or client-isolation rules that prevent devices from reaching each other.
  5. If the device has no working Wi-Fi, look for its blue light and setup network. After continuous disconnection, recovery setup opens after ten minutes.

The Wi-Fi setup page does not open

Join the watchsync network using password watchsync, remain connected despite a “no internet” message, and open http://192.168.4.1. If your phone switches back to another connection, temporarily disable that switching or use another phone or computer.

Select a 2.4 GHz network. Re-enter the password carefully and use manual entry for a hidden network. After setup succeeds, rejoin your normal network before opening watchsync.local.

I changed Wi-Fi and lost contact

Under Network settings, check the current IP address and web address. You can also change the hostname here without entering the Wi-Fi password again.

Join the new network and locate the new device IP in its router. A saved change applies only after a restart unless you chose Save and restart. If the new network cannot be reached, leave power on: recovery setup becomes available after ten minutes of continuous disconnection.

The device is waiting or not transmitting

  • Waiting for device time: check internet access. Under Radio/time settings, select Update device time, or hold the button for three seconds. A confirmed reply is required after every boot.
  • Preparing transmission: wait for a whole-minute boundary so a complete time message can begin.
  • Ready for next broadcast: check the schedule and time zone. Use Transmit for 1 hour for a temporary broadcast.
  • Paused: resume automatic transmission or start a one-hour pass.
  • Stopped · time expired: restore internet time access; the 23-hour limit cannot be extended by a manual pass.
  • Transmitter could not start: check Technical status and contact support with the firmware version and error.

The transmitter is green, but my watch will not sync

  1. Confirm that your watch supports the selected radio signal.
  2. Check the signal and time zone under Radio/time settings. For DCF77 use Central Europe and Automatic daylight saving.
  3. Check that automatic radio reception is enabled and that Watchsync transmits during the watch’s reception times. For an immediate test, start the watch’s manual reception procedure.
  4. Place the watch directly on Watchsync and keep it still for several complete messages. Range is limited. Try turning or moving the watch slightly and move nearby electronics away if needed.
  5. Check the watch’s own home-city and reception settings.

A green light confirms the transmitter’s state, not reception by the watch.

The watch shows the wrong hour

Check the transmitter’s selected time zone and daylight saving flag, then the watch’s own home-city/time-zone setting. Signal and time zone are independent. For DCF77, choose Central Europe with Automatic daylight saving, then request another watch reception and check the resulting time.

An update is unavailable or failed

Connect to your normal Wi-Fi network, finish any network scan and restart to apply pending network changes before updating. Select the Watchsync firmware file from Updates.

If an upload is interrupted, wait for the device to restart and check the running version before retrying. If the device stays unreachable, follow the USB installation instructions.

Still need help?

Use the support form and include your firmware version, watch model, signal/time zone, light colour and the steps that caused the problem. Include a screenshot or relevant Technical status lines, with network identifiers or other private details removed.

Share diagnostics

Open Help → Copy diagnostics on the local device page. Review the report, then include it when contacting support. If the captive sign-in window closes, remain connected to the setup network and open http://192.168.4.1 in your browser. A failed Wi-Fi attempt leaves setup available for another try.
