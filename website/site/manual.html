How Watchsync works

Watchsync obtains time from an internet time server over Wi-Fi. It encodes a selected radio time signal and drives the coil so a compatible nearby watch can receive it. It does not receive time from DCF77 or read your watch.

Each restart requires a new confirmed internet time update. After 23 hours without another confirmed update, transmission stops until a new reply is confirmed. A one-hour pass and a Wi-Fi reconnection do not bypass this limit.

Physical button

GestureResult
Single pressPause or resume automatic transmission. During a one-hour pass, pause all transmission. A single press waits 350 ms to distinguish it from a double press.
Double pressStart or end a one-hour pass, then return to the saved schedule or pause state.
Hold for 3 secondsRequest an internet time update. Releasing after the hold does not pause transmission.

Status light

ColourMeaning
BlueWi-Fi setup is active. Join the watchsync setup network.
PurpleStandby: Wi-Fi and confirmed time are healthy; transmission is paused or outside the daily schedule.
GreenTransmitting with recently confirmed time.
YellowWaiting for time, preparing a complete message, or an internet time update is late.
RedWi-Fi is disconnected. Transmission may continue while the last confirmed time remains valid.
Blinking redTime expired or the radio could not start; transmission has stopped.
OffThe light is disabled in settings, or the device is starting up. Check USB power if the device is also unreachable.

Use the text status on the device page as well as the light. LED output can be disabled under Radio/time settings.

Schedule and one-hour passes

Always on permits continuous transmission while automatic transmission is enabled and time is valid. Daily schedule permits transmission only between a start and end time. The times follow the selected time zone, including daylight saving changes.

A schedule can cross midnight, for example 22:00–05:00. Start and end must differ. Saving a schedule does not undo a manual pause. Wi-Fi and the web interface stay available between broadcasts.

A one-hour pass temporarily permits transmission outside the saved schedule or pause state. Its hour starts at a whole-minute boundary when transmission can begin. Ending it returns to the saved schedule or pause state. Restarting ends the temporary pass.

Radio/time settings

Tested with Casio Multi Band 6 watches. Watches from other manufacturers that support one of Watchsync’s transmitted time signals are also expected to work when configured for the matching signal.

Open Radio/time settings to choose the watch signal, time zone, daylight saving flag and status LED behaviour. Device details and Technical status remain in this section.

These are separate settings. Choose the signal supported by your watch and a matching time zone. Changing the signal does not select a time zone automatically. For DCF77 use Central Europe (CET/CEST), including in Sweden, and leave the daylight saving flag on Automatic.

Available encoders do not establish compatibility with every watch. Some watches apply their own home-city or time-zone settings. Verify the final displayed time against a trusted clock.

Save under Radio/time settings. A time-zone change stops an active transmission while it is applied; a complete frame starts at a whole minute when permitted. Manual pause stays in effect.

Network settings

Network settings shows the current IP address and a clickable web address, alongside the hostname and Wi-Fi configuration.

The default hostname is watchsync. Choose a different name for each device during initial network setup or change it later in Network settings.

The hostname and Wi-Fi network have separate save controls. Changing the hostname does not require re-entering the Wi-Fi password. Save for next startup keeps the current address until restart; Save and restart applies the new hostname immediately by restarting the device.

Names contain 1–32 lowercase ASCII letters, digits and hyphens, and must start and end with a letter or digit. After restart, open the web address shown for the new hostname or use the device IP. The old hostname stops being advertised.

Open Network settings to select a network or refresh the network list. Only 2.4 GHz is supported. Use manual network entry for a hidden SSID.

  • Save for next startup: retains the current connection. Restart later to apply.
  • Save and restart: applies the new network now. The browser disconnects during restart.
  • Restart to apply: applies a pending saved change.
  • Forget Wi-Fi: after confirmation, clears the saved network for the next startup. Restart to open setup.

Saved passwords are not displayed. Enter the password again when saving. After ten minutes of continuous Wi-Fi disconnection, the setup network becomes available while reconnect attempts continue. A recovered connection resets that timer.

Keep the device on a trusted local network. The device interface uses HTTP; do not forward its web port to the internet.

Firmware update

Firmware update is a standalone section on the device page. Open firmware update leads to the local upload page; updates are available through the normal Wi-Fi network.

Read the firmware update guide.

Factory reset

Factory reset is a standalone control at the bottom of the device page, below Help. Select Factory reset…, type RESET, then select Erase settings and restart.

Factory reset… requires typing RESET and confirming. It stops transmission and restarts, clearing saved Wi-Fi, hostname, radio settings, time zone and schedule. Installed firmware and OTA partitions remain. Interrupted cleanup retries at the next boot. A normal OTA update does not reset these settings.

After factory reset, join the setup network watchsync, password watchsync, then open http://192.168.4.1. The default device hostname is restored.

Placement and reception

Leave the watch directly on Watchsync overnight with automatic radio reception enabled. Watchsync must be transmitting when the watch attempts reception; choose Always on or a daily schedule that covers those times. Check your watch’s manual for its reception times and requirements. For an immediate test, start manual reception and keep the watch still for several complete messages. Range is limited. Try another orientation if reception fails; nearby power supplies, metal and electronics can affect reception.

The device’s Transmitting status describes its output, and Device time updated describes its internet time source. Neither confirms that your watch received a message. Check reception on the watch itself.

Device details and support

Under Radio/time settings → Device details, check the signal, antenna GPIO, carrier, last confirmed sync, time remaining and status light. Technical status opens a text diagnostic report at /status.txt.

Watchsync uses the classic M5 Atom Lite with the antenna connected to GPIO25.

See support and licensing for contact details and what to include in a report.

Time source and diagnostics

Under Radio/time settings → Device details, NTP servers lists the configured internet time sources: pool.ntp.org and time.nist.gov. This list does not identify which server supplied the last reply.

Under Help, choose Copy diagnostics to prepare a report with firmware version, uptime, reset reason, Wi-Fi signal and last disconnect reason, time-update age and memory status. If copying is unavailable, select and copy the displayed report. No Wi-Fi credentials are included and nothing is sent automatically. Help also links to the guides and contact form.
