Before updating

Download the firmware here, then upload watchsync-1.12.1.bin through Firmware update on your device’s local page.

  • Target: M5 Atom Lite, classic ESP32, antenna GPIO25. AtomS3 and other chips are not supported by this image.
  • Read the release notes and hardware requirements. Record your installed version and settings.
  • Keep USB power connected throughout the update. Use the normal trusted Wi-Fi network; updates are unavailable through the setup hotspot.
  • Finish network scans and apply any pending Wi-Fi or hostname change with a normal restart first.

Install an OTA release

The addresses below use the default hostname. If you renamed the device, substitute your chosen hostname or device IP.

  1. Download the release’s application file watchsync-1.12.1.bin. Do not use a bootloader, partition table, filesystem or merged/full-flash image.
  2. Open http://watchsync.local/update, or choose Open firmware update in the standalone Firmware update section on the device.
  3. Select the downloaded firmware file.
  4. Select Update firmware. Leave power connected while the file uploads, is verified, and the device restarts. Transmission pauses during flash writes.
  5. Wait for the page to report the running firmware version. Confirm it matches the intended release, then check Wi-Fi, settings and transmission.

Saved Wi-Fi and device settings are retained by the update path. A temporary one-hour pass ends at restart. A new confirmed internet time update is required before transmission resumes.

Keep Watchsync on your trusted local Wi-Fi network and use firmware from this page.

Release files and verification

Release assets include watchsync-1.12.1.bin, manifest.json and SHA256SUMS. The manifest records version, hardware target, application size and SHA-256 checksum. Check the target before uploading.

To check the downloaded file in Windows PowerShell:

Get-FileHash .\watchsync-1.12.1.bin -Algorithm SHA256

Compare the result with the release checksum. A matching checksum confirms file integrity against that published value; it is not a digital signature.
