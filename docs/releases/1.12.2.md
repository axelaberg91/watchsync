# Watchsync 1.12.2

Original release documentation by axelaberg91, CC BY-NC 4.0.

## Changes

This maintenance release updates how the firmware is built and packaged.
There are no functional source changes from 1.12.1 apart from the version
identifier. Wi-Fi setup, transmission schedules, saved settings and the local
device interface retain the same behavior.

Build paths use neutral prefixes. Release checks scan for recognized private
paths and validate the application image, hardware target, version and checksums.

## Target and installation

- Classic M5 Atom Lite, ESP32-PICO-D4; antenna output GPIO25.
- M5Stack ESP32 core 3.3.10, Minimal SPIFFS with OTA partitions.
- Wi-Fi configured on the device; local OTA updates always enabled.
- No compiled Wi-Fi credentials.
- Application-only `watchsync-1.12.2.bin`, manifest and SHA-256 checksums.

For an existing compatible installation:

1. Open `/update` on the device through your normal Wi-Fi network, or select
   **Open firmware update** in its Firmware update section.
2. If the installed firmware is 1.11.0 or earlier, enter its existing update
   password, normally `watchsync`. Firmware 1.12.0 and later do not require one.
3. Select `watchsync-1.12.2.bin` and keep USB power connected until restart.
4. Confirm that the running version is 1.12.2 and startup is confirmed.

Compatible saved settings are retained. A new confirmed internet time update is
required before transmission can resume. USB installation and recovery instructions are on the
[Watchsync website](https://watchsync.axelaberg91.workers.dev/diy.html#firmware).

## Verification status

Automated checks and the Atom Lite build passed. The application image and
release package were checked; `manifest.json` identifies the source commit,
hardware target, application size and SHA-256 checksum.

Physical OTA, interrupted-power recovery, watch reception and long-term device
stability have not been verified for this image.
