# Watchsync 1.12.2

Original release documentation by axelaberg91, CC BY-NC 4.0.

## Changes

This release prepares the firmware for the consolidated public repository.
Builds map workstation, Arduino core and library paths to neutral prefixes so
the distributed application does not contain local user-directory paths.
Packaging rejects recognized private paths and checks the application image,
target marker, version, staging profile and checksums.

The firmware's functional source is unchanged from 1.12.1 apart from the version
identifier. Wi-Fi provisioning, scheduled transmission, device settings and
the local update page retain the same behavior.

## Target and installation

- Classic M5 Atom Lite, ESP32-PICO-D4; antenna output GPIO25.
- M5Stack ESP32 core 3.3.10, Minimal SPIFFS with OTA partitions.
- AP-configured Wi-Fi and OTA always enabled; no compiled Wi-Fi credentials.
- Application-only `watchsync-1.12.2.bin`, manifest and SHA-256 checksums.

For an existing compatible installation, upload the application through the
device's Firmware update page on the trusted local network. Compatible saved
settings are retained. USB installation and recovery instructions are on the
[Watchsync website](https://watchsync.axelaberg91.workers.dev/diy.html#firmware).

## Verification status

The build workflow runs host regression checks and compiles and scans the Atom
application. A passing workflow does not verify physical OTA, interrupted-power
recovery, RF reception or long-duration device stability. No physical-device
validation is claimed for this packaging release.

The manifest identifies the exact source commit used for the package. Never
replace a previously published release with different application bytes.
