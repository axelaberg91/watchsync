# Watchsync 1.14.0 (unreleased)

Original release documentation by axelaberg91, CC BY-NC 4.0.
Inherited firmware and dependencies retain their separate licensing status.

## Changes

- Add **Advanced → Event log** with the latest 64 device events, newest first.
  Record confirmed NTP updates, actual transmission starts/stops and frequency
  tests, Wi-Fi connection changes and time/configuration/radio faults.
- **Refresh** reads the latest history. **Copy log** copies the displayed entries;
  when browser clipboard access is unavailable, select the displayed text.
- History remains available while the page is closed, but is held only in RAM
  and cleared by restart or firmware update. Device-local timestamps are shown
  when time was confirmed; earlier events retain their time since startup.
- Events contain no Wi-Fi credentials, network names or server addresses.
  A transmission-start event confirms transmitter activity, not watch reception.
  Radio timing, NTP configuration, schedules and saved settings are unchanged.

## Target and installation

Classic M5 Atom Lite, antenna GPIO25, M5Stack ESP32 3.3.10 and Minimal SPIFFS
with local OTA. This version is not yet published; use only a reviewed release
package when it becomes available. Compatible OTA retains saved settings.

## Verification

The firmware manifest records the exact source, target, toolchain, size and
checksum when packaged. Host tests cover bounded history, transitions, uptime,
UI failure recovery and copying. The pinned Atom build checks compilation.
Physical OTA, radio timing/reception and long-duration device operation require
separate testing; software checks do not establish those results.
