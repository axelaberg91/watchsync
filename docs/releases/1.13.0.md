# Watchsync 1.13.0

Original release documentation by axelaberg91, CC BY-NC 4.0.
Inherited firmware and dependencies retain their separate licensing status.

## Changes

- Choose default or custom NTP servers under **Network settings → Time source**.
  Custom mode accepts a primary and optional secondary hostname or IPv4 address,
  uses UDP port 123, and never adds public fallback servers. A local NTP server
  can provide time without internet access. IPv6 addresses are not supported.
- **Save and update time** saves and applies the configuration without a restart.
  Changing servers stops transmission until a new time update is confirmed.
  A complete frame starts at a whole minute when the saved schedule or one-hour
  pass allows it. Manual pause stays in effect.
- **Restore defaults** selects pool.ntp.org and time.nist.gov in the form;
  save to apply. Existing installations continue using those default servers.
  Saved custom servers survive normal OTA updates and restarts. Factory reset
  restores defaults. Invalid saved time-source records require correction.
- Device details and copied diagnostics show configured time sources and
  configuration errors. The server list does not identify the last responder.
  Time zone, daylight saving, three-hour sync interval and 23-hour time expiry
  remain unchanged. Choose a trusted server; fresh time is not proof of accuracy.

## Target and installation

- Standard classic M5 Atom Lite, ESP32-PICO-D4; antenna output GPIO25.
- M5Stack ESP32 core 3.3.10, Minimal SPIFFS with OTA partitions.
- Device-configured Wi-Fi, local OTA always enabled, no compiled credentials.
- Application-only `watchsync-1.13.0.bin`; no alternate GPIO image is included.

Open **Firmware update → Open firmware update** on your device's normal trusted
Wi-Fi network. Upload `watchsync-1.13.0.bin`, keep USB power connected until the
device restarts, and confirm version 1.13.0 and successful startup afterward.
Firmware 1.11.0 and earlier may request the existing update password, normally
`watchsync`; 1.12.0 and later do not require one.

Normal OTA retains compatible Wi-Fi, hostname, radio, time-zone and schedule
settings. A new confirmed NTP update is required before transmission resumes.
For first USB installation and recovery, use the
[DIY guide](https://axelaberg91.github.io/watchsync/diy.html#firmware).

## Verification

The manifest records the exact source commit, target, toolchain, application
size and SHA-256. Compare the binary with `SHA256SUMS` before uploading.
Automated configuration, transport, UI and regression checks and the pinned
Atom build cover software behavior. Physical OTA, local-server operation,
server failover, interrupted-power recovery, watch reception and long-term
device stability have not been verified for this image.
