# Watchsync 1.12.3

Original release documentation by axelaberg91, CC BY-NC 4.0.
Inherited firmware and dependencies retain their separate licensing status.

## Changes

The **Open the Watchsync website** link under Help now opens
[the Watchsync website](https://axelaberg91.github.io/watchsync/).
Wi-Fi setup, transmission schedules, saved settings and firmware updates retain
the same behavior as 1.12.2. No radio or hardware configuration changes are required.

## Target and installation

- Classic M5 Atom Lite, ESP32-PICO-D4; antenna output GPIO25.
- M5Stack ESP32 core 3.3.10, Minimal SPIFFS with OTA partitions.
- Wi-Fi configured on the device; local OTA updates always enabled.
- Application-only `watchsync-1.12.3.bin`, without compiled Wi-Fi credentials.

1. Open `/update` on the device through your normal trusted Wi-Fi network, or
   select **Open firmware update** in its Firmware update section.
2. If the installed firmware is 1.11.0 or earlier, enter its existing update
   password, normally `watchsync`. Firmware 1.12.0 and later do not require one.
3. Select `watchsync-1.12.3.bin` and keep USB power connected until restart.
4. Confirm that version 1.12.3 is running and startup is confirmed.

Normal OTA updates retain compatible saved settings. A new confirmed internet
time update is required before transmission can resume. First USB installation
and recovery instructions are in the
[DIY guide](https://axelaberg91.github.io/watchsync/diy.html#firmware).

## Verification

Check `manifest.json` for the exact source commit, hardware target, application
size and SHA-256 checksum. Compare the application with `SHA256SUMS` before use.
Physical OTA, interrupted-power recovery, watch reception and long-term device
stability have not been verified for this image.
